Crow Translate 非公式版 4.1.0-local.11 / Windows x64
================================================

このインストーラーには、Crow Translate本体、Qt、Tesseract、日本語・英語の
OCRデータ、Visual C++ランタイム、ライセンス文書を含みます。
インストール完了後、スタートメニューからCrow Translateを起動してください。
画面上の文字を認識するには「設定 → OCR」でエンジンを選択します。

本体のインストール中に、追加機能を導入するか「はい／いいえ」で選択できます。
「はい」の場合、Indra OCRと5種類の翻訳モデルを個別に選ぶ画面が開きます。
CAT-Translate-3.3Bを推奨し、Indra OCR・CATを初期選択しています。「既定で使う翻訳モデル」で、導入対象または
導入済みのモデルを選べます。候補のチェックを外した場合は既定を選び直してください。
新規導入時の既定はCAT-Translate-3.3B、更新・追加導入時は「既定を変更しない」です。
各項目の容量・ライセンス・利用条件を確認し、同意してからインストールします。
導入対象・既定モデルの選択と必要な同意がそろうまで、インストールボタンは無効です。
同意を取り消した場合や選択項目を変更した場合は、再び無効になります。
「いいえ」の場合、モデルやPythonのダウンロードは行いません。
後からスタートメニューの「追加機能のセットアップ」で導入・再試行できます。

アプリ内でも、設定ボタンのメニュー、トレイメニュー、または「設定 → 翻訳／OCR」の
「ローカルAIの管理」から6種類の追加機能を導入・修復できます。導入状況、容量、保存先と
ライセンス全文を表示し、必要な同意がそろうまでインストールボタンは無効になります。
別の保存先に導入済みのモデルがある場合は、その保存先を表示して再利用できます。
導入後は「この保存先・モデルを使用」で設定に反映します。設定画面から開いた場合、
反映は設定のOKを押した時です。キャンセルしても導入済みファイルは残ります。

OCRとキー操作
-------------
Ctrl+Shift+Z: 設定した遅延の後に画面の領域を選択し、OCRして翻訳します。
遅延時間は「設定 → OCR → キャプチャーの遅延」で変更できます。
Ctrl+Alt+IはOCR結果を入力欄に取り込む操作です。Ctrl+Alt+Oは遅延なしでOCRから翻訳まで行います。
「設定 → OCR」の「キャプチャー中はCrowのウィンドウを隠す」は初期状態でONです。
成功するとOCR結果を表示し、キャンセル・失敗時は元の表示・最小化状態へ戻ります。
遅延キャプチャーにも適用します。

主なアプリ内キー: Ctrl+Enterで翻訳、Ctrl+Shift+Xで翻訳中止、Ctrl+Shift+Vで入力へ貼付、
Ctrl+Shift+Cで訳文コピー、Ctrl+PageUp／PageDownで導入済みのローカルモデルを切替、
Ctrl+,で設定、Ctrl+Shift+Pで現在のローカルモデル／Codexの基本・追加指示、
Ctrl+Shift+MでローカルAIの管理を開きます。
「設定 → ショートカット」で編集・解除・初期化できます。重複するキーは保存できません。
他アプリとの競合でグローバルキーを登録できない場合は変更前の割り当てを復元します。
Ctrl+Shift+Zは更新時にも遅延付きの領域翻訳へ移行し、OCR反転などに残っている同じキーを解除します。
Ctrl+Alt+Gは読み上げ停止、Ctrl+Alt+Dは再生／一時停止です。旧版で保存されたGの重複も修復します。
それ以外の独自設定や、移行後に編集したキーは保持します。

追加セットアップは専用のPython環境も自動作成します。既存のPythonやPATHを変更せず、
選択した保存先にモデルと環境を置きます。保存済みの正しいファイルは再利用します。
導入成功後、不要なダウンロードファイルと専用pipキャッシュを削除します。
PLaMoは完成モデルを検証してから変換元の重み・変換用ソース・中間ファイルを削除します。
実行環境、完成モデル、トークナイザー、ライセンス、同意・導入記録、ログは保持します。
失敗・中断時は再開に必要なファイルを残します。削除できなかったファイルは警告します。
中止した場合はダウンロード・変換を終了し、完了済みの項目は残します。
アプリをアンインストールしても、この別保存先のモデルは削除しません。
Codex CLIはこの追加セットアップの対象外です。

モデルごとの条件
----------------
Indra OCR: コードはApache 2.0、モデルはModified OpenRAIL-Mです。用途制限と
商用条件があります。年収益・累計調達額2,000万米ドル超の場合の私的・研究以外の利用、
本人・所属先がDatalabやその関連会社と競合する製品・サービスを提供する場合の利用などは
別途許諾が必要です。競合に関する制限は用途を問わないため、必ず全文を確認してください。

PLaMo: PLaMo Community License。私的・学術用途以外の商業目的には、PFNへの
事前登録、年間売上・収益10億円以下などの条件があります。条件外は商用許諾が必要です。
Built with PLaMo. モデルは公式から約19.1 GB取得し、このPCで約6.24 GBに変換します。
変換時は80 GB以上の空き容量を用意してください。処理には時間がかかります。

Index-Translate 2B: Apache 2.0、モデル約1.31 GB。
Hy-MT2 7B: Apache 2.0、モデル約4.62 GB。
Seed-X-PPO 7B: OpenMDW。mradermacherによる非公式GGUF変換と公式トークナイザーを
使います。モデル約4.56 GB。各モデルのライセンスと出所表示を保存先に保持します。

Indra OCR
---------
追加セットアップで導入できます。手動の場合はPython 3.10以降で次を実行します。

  $indraEnv = Join-Path $env:LOCALAPPDATA 'Crow Translate/indra-venv'
  python -m venv $indraEnv
  & (Join-Path $indraEnv 'Scripts/python.exe') -m pip install indra-ocr

「設定 → OCR → Indra OCR (local)」で、作成した環境の
Scripts/indra-ocr.exeを指定してください。初回は約76 MBのモデルを取得します。

ローカル翻訳モデル
------------------
PLaMo-2-translate / Index-Translate 2B / Hy-MT2 7B / Seed-X-PPO 7B /
CAT-Translate-3.3Bに対応します。
翻訳先が「Auto (Japanese)」「Auto (English)」の場合も利用できます。
地域・数値書式を含むシステムの言語設定でも、英語・日本語を正しく認識します。
「設定 → 翻訳」で、ローカル翻訳モデルとCodexの「基本指示」「追加指示」を編集できます。
ローカル版はモデルごとに別々に保存します。モデルを切り替えても編集中の内容を保持し、
「OK」で保存、「キャンセル」で破棄します。「基本指示を既定に戻す」で元の文面に戻せます。
ローカル版の基本指示では {text} に原文、{source_lang}/{target_lang} に英語の言語名、
{source_code}/{target_code} に言語コードを挿入します。原文用の {text} は必須です。
追加指示は基本指示の前に付けます。例: 商品名は原語のまま残してください。
指示への対応はモデルにより異なります。PLaMoやSeedの専用記号も基本指示で編集できます。
Codexには原文と言語情報を別に渡します。基本指示と追加指示は通常の文章で記入してください。
Codexの既存の追加指示も引き継ぎます。空白の基本指示には既定文を使います。
「入力を文末（. / 。）で改行する」をONにすると、入力欄と翻訳へ送る文章を整形します。
小数・URL・メールアドレス・一般的な英文の略語を途中で切らず、既存の改行・空行を保持します。
既定はOFFです。ONの間は原文の簡略化より優先し、文章全体を一度に翻訳します。
ローカルモデルの「空けておくVRAM」は既定256 MiBです。小さくするとGPU配置を増やし、
GPUメモリー確保に失敗した場合は余白を増やして再試行します。GPU使用時は読み込み用の
メモリーマッピングを使わず、RAM常駐量を抑えます。収まらない部分はCPUで処理します。
NVIDIA環境ではnvidia-smiが利用できる場合、別アプリの専用VRAM使用量も考慮します。
追加機能セットアップで翻訳モデルを導入・更新すると、対応するNVIDIA GPUでは
CUDA 12.4ランタイムを追加取得します（約0.65 GB、展開後約1.2 GB）。モデルの
ライセンス表示にはNVIDIA利用条件も含みます。CUDAを優先し、利用できない場合は
Vulkan/CPUへ戻ります。CUDA Toolkitやドライバーの自動インストールは行いません。
PLaMoのCUDA実行は処理単位を16トークンにし、大きい単位での数値不良を回避します。
既存のモデルを再選択して更新しても、検証済みのモデルファイルは再ダウンロードしません。
CAT-Translate-3.3BはCyberAgentの正式版から作成した非公式のQ4_K_M版です（約2.07 GB）。
MITライセンスの原版・基盤モデルの著作権表示と公式チャット形式を保持しています。
全層がGPUに収まり、追加の空きもある場合は、通常CPUに置く入力埋め込みもGPUへ配置します。
GPU使用率はモデルの大きさや他アプリの使用状況で変わります。GPU側の確保量を含む
Windowsのコミット量は、実際のRAM常駐量とは異なります。

Codex CLIの検出
--------------
インストール先から起動してPATHが古い場合も、標準のユーザー用インストール先、
Windowsのユーザー・システムPATH、npmのネイティブ実行ファイルを探します。
「設定 → 翻訳 → Codex」の「自動検出」で見つかったパスを設定することもできます。
手動で指定した実行ファイルは優先します。Codexが未導入の場合は別途導入し、
codex loginを実行してください。Codex自体やログイン情報はこのインストーラーに含みません。
追加セットアップでは、Pythonと翻訳ランタイムも自動で導入します。
手動でソースから準備する場合はPython 3.14、Visual Studio C++ビルドツール、PowerShell 7が必要です。
Releaseのsource.zipをユーザーが書き込めるフォルダーに展開し、そのフォルダーで
READMEの「Managed local translation models (Windows)」の手順を実行します。
モデルの利用条件、ダウンロード容量、変換時の空き容量も確認してください。

追加セットアップの環境は、アプリを起動し直すと既定の参照先として検出されます。
新規ユーザーには導入成功したIndraをOCRの既定に設定します。選択した既定翻訳モデルは
検証成功後、アプリの次回起動時に反映します。失敗したモデルへは切り替えません。
「既定を変更しない」を選べば、手動指定した翻訳設定も保持します。変更する場合は保存先のlocal-translation、
またはlocal-translation/venv/Scripts/indra-ocr.exeを設定画面で指定してください。
英日自動切り替えには第一翻訳言語・第二翻訳言語を英語と日本語に設定します。
